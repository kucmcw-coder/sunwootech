계산기 공통 사용법

「평가계산」 탭의 모든 계산기는 같은 흐름으로 씁니다. 품목별 입력 항목은 각 품목 페이지를 보세요.

조사종류 고르기

  1. 맨 위 조사종류 칸을 누르면 품목 그림 목록이 열립니다(과수 · 논작물 · 밭작물 묶음).
  2. 품목을 먼저 누르면 그 품목에서 할 수 있는 조사만 펼쳐집니다. 예: 대추 → 수확개시 전 / 수확개시 후, 감귤 → 수확전 · 과실손해 · 동상해, 블루베리 → 꽃눈 · 꽃 · 과실.
  3. 조사를 누르면 계산기가 열리고, 고른 품목이 계산기 안에서도 미리 선택되어 있습니다.
  • 위쪽 검색 칸에 품목 이름(예: 녹두)을 쳐서 바로 찾을 수 있습니다.
  • 최근에 쓴 조사 3개가 맨 위에 나옵니다.
  • 조사종류 칸 옆 「?」를 누르면 지금 고른 품목의 설명서 쪽이 열립니다.

기본 흐름

  1. 농가명을 적습니다. 저장 파일과 이력에 이 이름이 붙습니다.
  2. 계약 정보를 넣습니다. 가입금액, 평년수확량, 자기부담비율, 가입주수·면적 등 전산의 계약 사항을 그대로 옮깁니다. 금액·면적 칸에는 천 단위 콤마(1,234)가 붙습니다.
  3. 현장 조사값을 넣습니다. 가입면적을 넣으면 실제경작면적, 가입주수를 넣으면 실제결과주수가 같은 값으로 자동 입력됩니다. 다르면 그 칸만 고치세요. 고사·미보상·표본 값도 넣습니다.
  4. 결과를 확인합니다. 입력하는 즉시 수확량, 피해율, 예상 보험금이 계산됩니다. 화면 맨 아래 줄에는 피해율이 늘 보입니다.
  5. 저장합니다. 맨 아래 줄 오른쪽의 조사서·이력·리포트·공유 버튼을 씁니다.
주수·면적이 계약과 다를 때 (계약변경 기준)
  • 과수: 품종·수령별로 가입주수와 실제결과주수 차이가 5% 이내면 계약의 평년수확량·가입금액으로 계산합니다(전산과 같음). 5%를 넘으면 계약변경 대상으로 표시합니다.
  • 논밭작물: 가입면적과 실제경작면적 차이가 10% 이내면 계약 값, 10%를 넘으면 계약변경 대상으로 표시합니다.
  • 모든 계산기에서 계약변경 대상이면 비교한 값과 차이(%)를 함께 보여 줍니다.
  • 가입금액은 줄어들 때만 반영되고, 늘어나지는 않습니다.

표본 줄 버튼

표본구간(표본주) 표 아래와 품종(수령)별 주수 표 아래에 같은 모양의 버튼이 있습니다.

버튼하는 일
➕ 추가 / + 품종 추가줄을 하나 늘립니다.
➖ 마지막마지막 줄을 지웁니다. 적정 표본수보다 많을 때만 지워집니다.
↺ 리셋입력값을 모두 지우고 적정 표본수로 되돌립니다.

실제경작면적·조사대상주수를 넣으면 적정 표본수가 바로 맞춰집니다.

표본칸 점검 표시

표본 칸은 빈칸과 0을 모두 표본으로 셉니다. 실수로 비운 칸을 찾기 쉽도록 색으로 표시합니다.

색뜻
노랑필요한 표본 수 안에 있는데 값이 0이거나 비어 있음 → 정말 0인지 확인
파랑필요한 표본 수보다 많이 입력한 칸
빨강필요 이상으로 입력했는데 값이 0이거나 비어 있음

저장과 공유

  • 📸 리포트: 지금 계산 화면 전체를 한 장의 이미지로 저장합니다. 좌우로 밀어야 보이는 넓은 표도 전부 담깁니다. 파일 이름은 품목계산기_날짜시각입니다.
  • 📄 조사서: 모든 계산기에서 종이 현지조사서에 옮겨 적기 쉬운 표로 저장합니다. 파일 이름은 품목조사서_날짜시각입니다.
  • 💾 저장 / 조사이력: 입력값 전체를 이력으로 남겨 나중에 그대로 불러옵니다. 여러 농지를 차례로 조사할 때 씁니다. Pro
  • 공유: 저장한 이미지를 카카오톡 등으로 바로 보냅니다.
조사서 글씨 색 (브로콜리·콩·팥·녹두·참깨 등 새 양식)
  • 노란 칸 · 파란 글씨 = 종이 조사서에 옮겨 적을 값(입력한 값)
  • 검정 굵은 글씨 = 자동 계산된 값
  • 회색 글씨 = 검산용 값(표본별 유효중량·면적·피해주수·손해정도비율 등)
조사서는 종이 양식과 똑같지는 않습니다. 조사·입력한 내용만 정리하고, 조사하지 않은 항목은 넣지 않습니다.

화면 조절

  • 「크게」「작게」로 입력칸 글씨 크기를 바꿉니다.
  • 「전체 싹 지우기」는 지금 계산기의 입력값을 모두 지웁니다. 다음 농지로 넘어갈 때 쓰세요.
무료 버전은 앱을 켤 때마다 계산기를 5회까지 쓸 수 있고 조사이력은 저장되지 않습니다.

전산과 값이 다를 때

앱은 전산의 끝자리 처리(내림·올림·반올림)를 품목별로 따르도록 맞췄지만 모든 경우를 확인하지는 못했습니다. 값이 다르면 앱 화면과 전산 화면을 함께 캡처해 오류 제보로 보내 주세요.
