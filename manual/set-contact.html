오류 제보와 문의

불편한 점은 화면 그대로 알려 주세요. 보내 주신 제보로 고친 기능이 많습니다.

오류 제보

  1. 「설정/도움」 탭에서 「🐛 오류 제보」를 누릅니다. 제보 양식이 열립니다.
  2. 무엇을 하려다 어떤 일이 생겼는지, 기대한 결과와 실제 결과를 적습니다.
  3. 화면 캡처를 첨부합니다. 원인을 찾는 데 가장 큰 도움이 됩니다.
  4. 계산값 문의라면 입력한 값과 전산 결과 값을 함께 적거나, 앱 화면과 전산 화면을 같이 캡처해 주세요.

메일 문의

「✉️ 메일 문의」를 누르면 앱 버전과 기기 정보가 자동으로 들어간 메일 창이 열립니다. 정보를 지우지 말고 내용만 덧붙여 보내 주세요.

빨리 해결되는 제보

  • 주소 검색 문제: 입력한 검색어 그대로 (예: 고포리 1-50)
  • 면적 문제: 지도 화면 캡처와 비교한 기준 면적
  • 계산 문제: 품목, 조사종류, 앱 화면과 전산 화면
  • 설치·업데이트 문제: Play 스토어 오류 화면
앱이 마음에 드셨다면 Play 스토어에 리뷰 한 줄 남겨 주세요. 다음 업데이트에 큰 힘이 됩니다.
