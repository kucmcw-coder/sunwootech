단위·언어·글씨 크기

면적·길이 단위

면적은 ㎡와 평이 함께 표시되는 것이 기본입니다. 「설정/도움」 탭의 단위 설정에서 주 단위와 보조 단위(예: ㎡ + 평, ha, 에이커)와 길이 단위를 바꿀 수 있습니다. 해외에서는 ㎡·ha(미국은 에이커)가 기본입니다.

언어

한국어, 영어, 스페인어, 포르투갈어를 지원합니다. 처음에는 폰 언어에 맞춰 정해지고, 「설정/도움」 → 「⚙️ 설정」의 「🌐 언어」에서 직접 바꿀 수 있습니다. 계산기는 국내 손해평가 업무용이라 한국어 화면을 기준으로 합니다.

면적 표시 기준

「⚙️ 설정」 언어 줄 아래 「📐 면적 표시 기준」에서 고릅니다. 버튼을 누르면 아래에 설명이 나옵니다.

  • 측정값: 지도에서 잰 면적 그대로. 지번 자동 그리기 구역은 공부상 면적과의 오차(%)도 함께 표시합니다.
  • 공부상 면적: 지번마다 측정 면적이 공부상 면적을 넘으면 공부상 면적으로, 넘지 않으면 측정값 그대로 보여 줍니다(인터넷 필요).

면적 보기 (간단히 / 자세히)

「⚙️ 설정」의 「🔍 면적 보기」에서 [간단히 | 자세히]를 고릅니다. 간단히는 면적과 주소만 크게, 자세히는 둘레·점 개수·오차까지 모두 보여 줍니다. 면적측정 화면에서 주소를 한 번 눌러도 바로 바뀝니다.

계산기 글씨 크기

평가계산 화면 위쪽 「크게」「작게」로 입력칸 글씨 크기를 바꿉니다.

지도 표시 설정

면적측정 화면 왼쪽 「🎛️ 표시 설정」에서 아래 항목을 켜고 끕니다.

  • 💡 설명 숨김: 버튼 옆 글씨
  • 🏷️ 면적 숨김: 지도 위 면적·길이 글씨
  • 📍 위치 숨김: 내 위치 화살표
  • 🧭 나침반 표시/숨김
