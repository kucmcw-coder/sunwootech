Backup and restore

Measurement history and records are stored only on this phone. They are lost if you delete the app or change phones, so make a backup file from time to time.

Making a backup

  1. Open “⚙️ Settings” in the Settings tab.
  2. Tap one of the two buttons.
    · ⬆️ Data only (light, recommended): without photos. The photos stay in your gallery.
    · 🖼️ With images: includes photos, so the file is larger.
  3. Keep the backup file somewhere safe: email it to yourself, or save it to Google Drive.

Restoring

  1. On the new phone (or after reinstalling), tap “⚙️ Settings” → “⬇️ Import backup file”.
  2. Choose the backup file.
  3. It is merged with the current data. Records that already exist are not added twice.
Always make a backup before deleting the app — including when you reinstall because an update fails.
